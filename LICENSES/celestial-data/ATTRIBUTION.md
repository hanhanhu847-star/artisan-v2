# 十二星座数据与图版

Stellarium 团队（modern 连线）与 David Nash / Astronexus（HYG 星表）；ARTISAN / hanhanhu847-star 制图（Codex辅助）。
坐标和星等使用 [HYG v4.0](https://raw.githubusercontent.com/astronexus/HYG-Database/c7f7f883fe678cc7680169a50ccd7dcc49b060ce/hyg/CURRENT/hygdata_v40.csv.gz)；连线使用 [Stellarium modern](https://raw.githubusercontent.com/Stellarium/stellarium/d6c7677f24e679019015e385f6a5b208d8f49026/skycultures/modern/index.json)，许可说明见该项目 description.md。仅使用数据，不使用原插画。

数据子集与据此重绘的十二幅 SVG 均按 CC BY-SA 4.0 分发。改动：筛选、切平面投影、重绘刻度、星点、图例和中英文标签。本段与来源链接应随这些图版保留，改编仍按相同许可发布。IAU 定义星座天区边界，不规定唯一的连线。本图不绘制官方边界，不代替观测星历。
