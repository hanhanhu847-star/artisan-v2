# 设计软件、Office 与排版
1. 在 BROWSER/index.html 里按风格和素材类别筛选，点击原文件或复制路径。直接拖入 SVG 可保留矢量；透明 PNG 适用于不支持 SVG 或不希望字体变化的场景。
2. 建立 1920×1080 画板，放入同规格 JPG 作底；另开透明图层放角花、分隔线、插图，字放在平整的空白区域。做竖版海报改用 portrait.svg。
3. 需要纯粹结构图，直接打开对应 illustrations SVG；组和路径可以编辑。SVG 中有文字的组件视觉稿会调用系统字体，跨平台发布前核对字体替换和文本溢出。
4. PowerPoint/Word 插入原文件，不截取 PDF 预览。在支持 SVG 的版本中可按软件能力转换为形状。大尺寸海报用矢量母版；印刷输出前自行做目标纸张和工艺打样。
5. 纹理按原周期重复，改变纹理方向时保持相邻块一致。设计图层透明度不改变原文件许可；改变照片取景、调色或合成请在项目来源备注中记录。
