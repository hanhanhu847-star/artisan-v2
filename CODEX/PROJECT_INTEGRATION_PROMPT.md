# 将 ARTISAN 接入已有工程
在目标工程中先读项目约定和当前版本，定位要修改的具体页面、组件与样式作用域。新建资源目录，避免覆盖原素材或批量替换全局图标。项目若已有主题变量，写好 ARTISAN 变量到项目变量的映射。

根据我指定的用途筛选 ASSET_INDEX.json；若未指定流派，依据任务选择一个，说明它怎样帮助该页面。主界面最多使用一个装饰主焦点。先用真实图制作一个代表性页面，验证可读性与操作后再扩展。

把每项使用记录保存为清单：源 asset_id、原路径、目标路径、用途、许可与修改。复制所需 LICENSES 文件。不要去掉摄影来源，不下载任何未列在任务中的第三方素材。原生平台应复用语义色、图形语言和状态设计，不直接照搬 CSS。

运行宿主本来要求的检查。检查 1×/高像素密度、窄屏、深浅背景、悬停、选中、禁用、错误、空状态。实际操作点击保存、加载失败、取消返回等相关流程。保留可回退版本，给出可查看的结果入口。
