# 工程蓝图 / Blueprint / V2

## 本包的视觉语言
正视与剖视并列，使用投影线、轴线、尺寸箭头及直角坐标。 主图占三分之二，角落放信息栏；引线避开交叉。
弱网格和浅刻线；主轮廓线宽大于辅助线。

本套 238 个源素材文件，按家族计 112 个独立作品。V1 的130个源文件保留，新增文件含升级、原创和格式版本；数字不将不同尺寸或五态拆算为作品。

## 原件与应用
背景 v2-plate-01 至09各自为独立构图；JPG与SVG为同家族。01至03横版3840×2160，04至05竖版2160×3840，06至07方版3000×3000，08至09超宽5120×1440。加上V1的4K母版和摄影，共11幅背景。
纹理使用12个原生2048连续平铺WebP和4个透明PNG叠层。旧384px版本保留。装饰选单独SVG，图标以64单位画板绘制，可按设备像素密度导出。
UI共15组：14类基础组件V2视觉重排和1组工具栏。旧五态与新默认图形并非自动配套；宿主应用应同步实现焦点、错误、禁用、选中和点击区。
直角接点、标距线、分栏题头；状态同时显示文字。 按压120ms、状态200ms、面板280ms可作起点；减少动态时直接显示终态。

## 使用判断
适用：工程类界面、原理说明、科技展板。
避免：装饰性标注不能伪装为制造公差或可计算尺寸。
搭配：结合瑞士分栏可做技术文档。
